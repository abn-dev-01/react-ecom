# Study Plan — E-Commerce Storefront (React / Next.js)

Project goal: become a Senior Front-End Developer through hands-on, feature-driven learning, using this storefront as the single evolving project.

Stack: React, Next.js (App Router), TypeScript, Tailwind CSS.

## Module Sequence

Each module has a concrete deliverable built inside the storefront.

1. **React Fundamentals & Mental Model**
   JSX, props/state, core hooks.
   Build: static product card + product list render.

2. **Reusable Components**
   Composition, prop design, compound components.
   Build: Button/Card/Layout primitives, product grid.

3. **Responsive UI (CSS + Tailwind)**
   Layout systems, breakpoints, design tokens.
   Build: storefront shell, nav, responsive grid.

4. **Forms & Validation**
   React Hook Form + Zod, accessible errors.
   Build: variant selector, address/checkout form.

5. **Async & API Communication**
   Fetch patterns, loading/error states, client-side caching.
   Build: catalog fetch, cart sync, search.

6. **Next.js App Router & Data Fetching**
   Server/client components, routing, server actions, ISR/revalidation.
   Build: product & category pages.

7. **Auth & Protected Routes**
   Middleware, session handling.
   Build: account area, protected checkout.

8. **Testing (Vitest + RTL)**
   Unit + integration tests, API mocking.
   Build: tests for cart and checkout flows.

9. **Frontend Architecture**
   State management choice, folder structure, refactoring, performance.
   Build: refactor cart/state layer at scale.
